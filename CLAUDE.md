# Project

This project goal is create an desktop application for 3D Drone simulation. Based on C++23

- Project name: Drone Simulator
- Code C++23
- Graphics engine OpenGL >4.5
- GUI library: Qt6 (Only Graphical)
- Building system CMake + Ninja
- Generate doxygen and markdown documentation
- Each user have his own database (sqlite3) in $HOME/.drone_simulation
- Test:
    - unit test
    - integration test


# Description

- Main Window with 3D flight simulation (Terrain + Sky) (OpenGL context). 
- Tab Menus

# Modules
- Graphic Engine
- Items manager
- Terrain Generator
- Main event loop
